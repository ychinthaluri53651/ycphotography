# Adding photos

1. Drop photos into the folder for their category, for example `weddings/`.
2. Name each file after what it shows, e.g. `bride-at-the-mandap.jpg`.
   The name becomes the photo's description on the site.
3. Commit and push.

GitHub then resizes the photos, adds them to that category on the portfolio
page, and removes the originals from this folder. The site updates a minute
or two later. Run `git pull` afterwards to get those changes on your computer.

Folders: weddings, couples, family, kids, portraits, events, travel
Formats: JPG, PNG, WebP, TIFF, HEIC
